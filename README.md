# Expense Management

Простой проект на Flask для управления расходами и доходами малого бизнеса.

## Структура проекта

- `app/` — основное Flask-приложение
- `app/routes/` — маршруты и бизнес-логика страниц
- `app/templates/` — HTML-шаблоны
- `app/static/` — CSS, JavaScript, изображения
- `instance/` — локальные данные SQLite
- `config.py` — конфигурация приложения
- `run.py` — точка запуска

## Запуск

1. Создайте виртуальное окружение:
   python -m venv .venv
2. Активируйте его:
   .venv\Scripts\activate
3. Установите зависимости:
   pip install -r requirements.txt
4. Запустите приложение:
   python run.py

Откройте адрес: http://127.0.0.1:5000
